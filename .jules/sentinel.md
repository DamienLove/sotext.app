## 2024-03-27 - Migrated Hardcoded process.env Secrets to defineSecret()
**Vulnerability:** Use of process.env for sensitive credentials (API keys and SMTP passwords) in Firebase Functions.
**Learning:** Firebase Secret Manager (defineSecret) provides a more secure way to handle secrets, encrypting them and making them available only during function execution. To access secrets during execution, clients or external services (like nodemailer transporter) must be initialized lazily inside the function handler.
**Prevention:** Use defineSecret() for all sensitive credentials in Firebase Functions and initialize services that require them lazily inside the function handler.
