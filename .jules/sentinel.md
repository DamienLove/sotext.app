## 2025-02-14 - Lazy Loading Secrets in Firebase Functions
**Vulnerability:** Firebase Functions relying on `process.env` for secrets at module load time are insecure and can crash if secrets are unavailable globally.
**Learning:** `defineSecret()` from `firebase-functions/params` must be lazily evaluated inside the function handler (e.g., `emailUser.value()`) because the secret payload is not injected until runtime. Instantiating external services (like `nodemailer`) using these secrets at the module scope will result in empty/undefined values.
**Prevention:** Always declare `defineSecret()` at the module level, pass them to `.runWith({secrets: [...]})` or `.onCall({secrets: [...]})`, and only invoke `.value()` and initialize dependent services *inside* the function handler.
