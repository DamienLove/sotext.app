## 2025-04-09 - Chained Array Operations in React useMemo
**Learning:** In the web application's React components, chaining `.flat()`, `.map()`, and `.filter()` operations alongside spread operators inside a frequently running `useMemo` block creates unnecessary intermediate array allocations and causes memory bloat. A strict `Array.isArray()` check when replacing `.flat()` might silently drop elements if the original array structure was mixed.
**Action:** Replace chained declarative array operations inside performance-critical `useMemo` blocks with imperative single-pass loops to reduce garbage collection overhead, ensuring the logic properly accounts for non-array elements when refactoring `.flat()`.
